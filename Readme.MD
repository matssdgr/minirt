miniRT

Description

A simple ray tracer written in C with the MiniLibX. It reads a .rt scene file and renders spheres, planes and cylinders with ambient light, diffuse light and shadows.

Instructions

Compile the project with make, then run the program with a scene file as argument: ./miniRT scenes/basic_sphere.rt

The scene file must have the .rt extension. Press ESC or close the window to quit.
